# ระบบจัดการการแข่งขันกีฬาสหวิทยาเขตโซ่พิสัย-ปากคาด 2569

เว็บแอปหน้าเดียว (index.html) ใช้ Supabase เป็นฐานข้อมูลและระบบเข้าสู่ระบบ

- ผู้ชม: เปิดเว็บดูโปรแกรม ผล เหรียญ ข่าว ได้ทันที ไม่ต้องมีบัญชี
- ผู้ประสานงานโรงเรียน: เข้าสู่ระบบด้วยชื่อผู้ใช้/รหัสผ่าน ส่งรายชื่อนักกีฬาของโรงเรียนตนเอง (จนถึงวันปิดรับรายชื่อ)
- ผู้ดูแลระบบ: จัดการทุกอย่าง และสร้างบัญชีผู้ประสานงานได้ที่เมนู “ตั้งค่าระบบ”

รายชื่อนักเรียนไม่เปิดเผยต่อผู้ชมทั่วไป (ควบคุมด้วย Row Level Security ในฐานข้อมูล)
